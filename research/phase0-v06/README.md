## 文件
- sources.csv：全部来源、访问深度及说明；来源编号稳定。
- topic_register.csv：H01–H30 资料范围、关联来源、可用资料和待获取项。`数表`表示至少一组结构化数据；`摘录`表示事实或研究摘要；`目录`表示以档案定位为主，并非完成状态。
- economic_observations.csv：原始观测、基期和单位。新增进口、出口、粗钢、汇率、小麦。月度未季调，名义法郎金额不等于实物量。未做插值。
- demography.csv：人口普查、出生死亡；OCR修订值明确标记。
- election_seats.csv：官方历史概述选举席次。election_votes.csv 已与国民议会网页的 Lachapelle 原表转录逐项核对；election_votes_prior_transcription.csv 为上一轮存档；election_turnout.csv 保留不同分母。
- organization_observations.csv：会员规模，保留约数和下限。
- social_observations.csv：住房计划量、失业估计、集体协议数量等。
- legislation.csv：17项法案提交、颁布、公布日期；parliamentary_votes.csv：部分两院表决，冲突数字保留。
- events.csv：事件研究索引，非逐日完整年表。精度为 day/month；标记未复核日期。
- chamber_groups.csv、senate_groups.csv、government_heads.csv、sfio_meetings.csv、sfio_votes.csv：保留增量02记录及原始限制。
- discrepancies.csv：口径冲突和需要复核的陈述。
- audit.json：结构检查；不等于历史准确性全面认证。
