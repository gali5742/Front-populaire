# 游戏设计理念
状态：已讨论确认的原则及后续实现约束；细节可经试玩修订。

## 玩家与目标
玩家采取SFIO当前合法中央领导层的制度性决策视角（D80），CAP是产生集体决议的议事机关，而非玩家可直接控制的全体委员；玩家不绑定某一历史人物或派系，也不是所有左翼组织或法国国家的无条件控制者。执政前后权力不同，议会、参议院、盟友、党内程序、工会、雇主及外国行为者保留各自的政治意愿。即使社会党入阁，也不能任意指挥政府的所有部门。政治结果不必重演真实人民阵线历史；历史情境与制度提供约束，玩家选择和外部主体共同决定发展。

## 核心体验
- 每月阅读政治简报，了解需要回应的事务；选择有限的政治行动，与其他主体接触、争取党内授权、开展组织及宣传、参与议会事务、应对群众运动。
- 由实际政治反馈而非属性涨跌主导体验。谈判、党内辩论、代表表决、联盟协议、议会阻力、政策实施与延迟效果是核心。
- 玩家不必最大化每个指标，也不必用尽每次行动或处理每项限时机会。拒绝、维持现状、暂缓等应是合理的政治选择。
- 政治行动需有明确的内容、可知条件、成本及可能后果。政治结果具有不确定性，其他主体可能拒绝、附加条件或延后回应。
- 具体行动卡是主要交互对象，机构是分类及政治信息来源，不是首页六个功能菜单。
- 政党不是玩家的属性栏。党内派系具有政治立场与利益；工会不是党的附属资源；党内授权与联盟承诺具有实质约束。

## 简化原则
不是维多利亚3式经济、人口、地理管理游戏，也不是图表阅读游戏。无独立经济经营、产业经营或地区经营循环；经济以四个状态支持政治叙事。后台可以比前台复杂，但复杂度须服务于政治选择，而非迫使玩家记账或刷属性。
历史上存在的制度不必全部模拟；保留对政治结果具有必要解释力的部分。真实内阁职位遵循历史设置，不为减少界面元素而合并部长／国务次官。若体验确实困难，再经验证修改。

## 设计边界
不增加含义模糊的综合政治影响力点数，不公开所有后台修正公式及危机触发阈值，不把社会支持率或党内团结当作首页常驻仪表盘。不以预设的最优路线、历史任务清单或固定推荐行动替代开放政治过程。
精确评分、结局判定、难度模式、具体经济/行动参数以及实现框架尚未最终核定。本文件不是对这些未决内容的批准。
