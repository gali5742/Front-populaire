## 2. 党际关系不是单一好感度
| 维度 | 数据来源及边界 |
|---|---|
| 政治意见 | 具体议题、方案版本及最近可知表达；不据此推断所有内部立场 |
| 合作身份 | 真实联合机构、共同纲领或合作安排的参与资格及有效时点 |
| 正式协议 | 当事方、适用范围、具体条款、有效版本及生效/终止条件 |
| 实际履约 | 已到期义务、履行事实、异议及违约/补救；不等于协议存续 |
| 议会支持 | 某政府、信任或特定议案的承诺和实际表决；由D5核定 |
| 内阁参与 | 实际任命及职务关系；由D5核定；联盟不自动生成内阁席位 |
可以同时存在合作、政策分歧、部分履行及不同议会行为。联盟不是不可逆阶段树，不能以某个标签推定共同立场。多边联合机构如实际形成可有自身议程与资格，但无独立联盟资源或玩家控制所有成员；不把每次双边协议都包装成新组织。成员资格与所有签约/适用方独立查询；退出某合作安排不自动退出其他协议或内阁。UI04-02从上述同源事实投影，普通状态深灰；无实际议题不设通用改善关系/拉拢按钮。

## 3. 磋商实例、方案与回应
从具体议题发起。可由SFIO或自主主体发起，既可公开也可在实际接触渠道内进行。记录议题ID、实例ID、发起方及所代表组织、必要参与方、可选参与方、各自权限、实际截止/收束条件、条款变体空间、版本、往来、答复状态、成本引用及真实成立结果。参加会谈不等于接受方案；表达赞成目标不等于对有效版本作出具有约束力的同意。D3领导层更替后按组织承接原则及新授权重验；可接收已发送提议的回复。
| 程序节点 | 规则 |
|---|---|
| 接触与探询 | 按实际职权了解意见；不自动取得谈判或签署权 |
| 提出方案 | 明确条款、必要当事方与当前有效版本；校验授权、时限及可行性 |
| 等待、答复 | 记录接受、拒绝、附条件回应、反建议、明确延后或未回复；等待不推定同意/拒绝 |
| 反建议与修订 | 仅限议题的合法有限条款空间；D2去重、收束与版本规则 |
| 内部批准 | 需要时由各方实际有权机关决定；玩家不能直接控制他党内部批准 |
| 成立与生效 | 必要当事方对同一有效版本按实际程序同意；满足签署、批准、条件及生效时间 |
| 未果、撤回、到期 | 保留已发生的声明、成本及有限成果；不凭空生成有效协议 |
可按实际事项合并步骤，不要求所有磋商逐项经过上表。不预设统一等待一个月，响应时点取决于实际程序、主体行为及期限；普通回复可在正常窗口展示，月底中断只限D1真实必答截止。附条件同意如条件已在共同版本内且确实满足，按其实际法律/政治效力处理；新条件构成反建议，不将条件性表态静默计入无条件最终同意。多方谈判若一方拒绝，不将缺少必要方的方案自动成立；若其他方拟另行签订范围较小的协议，须形成明确的当事方与有效版本、重新校验必要同意和授权，不把原多边协议标成已全部成立。秘密立场不从选项禁用原因或“成功率”泄露。给玩家实际声明、条件、已知分歧及后续合法路径；不编造拒绝理由。等待不自动产生付费项目或“查看工作”入口。

## 4. 协议与联盟义务
协议为政治事实对象，不是增益卡或永久解锁。最小记录：协议ID、相关议题、类型、版本、实际当事方/代表权限、签订日期、批准/生效条件与时间、适用范围、条款、责任主体及受益/相对方、期限、例外、改约/加入/退出程序、替代关系、实际履约及争议记录。可根据真实来源区分政治声明、统一行动协定、共同纲领、选举协调、议会支持安排、联合执政安排与劳资协议；不是固定等级或每个协议必有全部条款。声明或纲领中无明确执行义务的主张不得被编造为可强制履约的硬约束。
| 可配置条款 | 示例作用（虚构） |
|---|---|
| 合作目的与范围 | 反法西斯共同活动，而非全政策联盟 |
| 共同活动与执行责任 | 各方独立组织并按约协调；不转移组织控制权 |
| 共同政策主张 | 列明共同支持的政策目标、范围与保留事项；立法和行政由D5 |
| 选举协作 | 适用选举、选区范围、退选原则及例外；D6负责候选资格、具体票转移 |
| 议会与参政 | 区分支持特定政府/法案与参阁承诺；不代替实际表决或任命 |
| 有效期限及调整 | 实际生效、期限、加入/退出、修订所需同意与程序 |
协议签订、当前效力及履约三者独立。单一状态不能掩盖条款差异：协议可已签署待生效、有效、按实际程序暂停、终止/到期；条款可适用/未触发/待履行/已履行/部分履行/逾期未履行/有争议/依法免除等。是否允许暂停、免除、自动终止须由具体条款规定，不添加通用“违约即失效”。历史签署日期始终保留，不把修订或加入日期重写成初次签约。
义务记录从实际生效条款生成，按责任方、适用时点、触发条件、所要求行为/禁止行为、完成证据和例外判定；同一义务实例只生成/结算一次。未到期不算违约；客观无法履行、政治拒绝、双方对条款解释不同及实际未履行区分，不默认任何短缺都是恶意违约。违约可产生具体质疑、谈判条件、合作暂停提议、公开批评等政治后果，须有因果桥梁与各方自主决定，不以全局关系扣分或自动解散联盟代替。义务需要执行的行动仍按D1/D3实际权限、成本与条件校验；对其他主体的政治承诺不赋予直接指挥其行为的能力。
修订与退出沿D2/D3：变更只在实际程序满足时影响未来有效条款，保留已发生履约与成本；新版本同意不可拼接，加入方明确承诺范围，原当事方义务不能被无权主体修改。退出生效前仍按有效义务处理；已有约束力的欠付或终止后仍存义务按具体规则保留。党内撤销授权不自动终止外部协议；禁止越权执行但生成真实需处理的履约冲突，可能重新授权、协调改约、依法退出或记录未履行后果。结构化条款冲突与澄清沿D3-R03，检测器不自动制造政治议程。D5/D6不得将联盟成员自动投同一票、自动退选或保证选票转移。

## 5. 自主群众运动的最小模型
群众运动是具体政治/社会事务的行为过程，不是可以储存和消耗的动员力。参与主体包括实际存在的工会（如CGT/CGTU）、行业或地方工会/基层组织、工人群体、雇主及其组织、相关政治团体；国家与行政机关依D5。普通成员不是全量个人代理；重要行业或地方活动按实际意义聚合，避免地图、产业经营与逐厂操作。保持工会组织正式决定、基层实际参加及非会员参加分离，SFIO支持不等于工会接受，不等于工人一定参加。
| 记录 | 最小必要内容 |
|---|---|
| 社会主体 | 组织身份、有效时期、相关代表、组织基础及自主诉求；具体能力而非通用资源 |
| 社会诉求 | 工资、就业、工时、集体协议、劳动权利或具体政治事件等有来源的问题与方案 |
| 运动实例 | 关联议题、发起者及实际参与群体、活动类型、适用地域/行业范围、开始及阶段时点、公开要求、组织间协调关系、实际行动/状态及结果 |
| 劳资协商 | 独立实例、实际谈判方、争议条款、回应与义务；可关联运动但不等于运动本身 |
| 报告 | 发生/获知时间、渠道、覆盖范围与不确定性；按D2可见性 |
工会会员数量是组织事实/校准依据，不是可直接消费的动员点，也不等同于所有罢工参与者。初版活动规模采用具有范围含义的有限状态（例如局部、多个行业/地区、全国性协调；这些是范围描述，不是单一升级等级），在有依据时展示实际统计及口径。不虚构精确每月参加人数、强度条或预报成功率。运动可同时具有不同地区、行业、参与者和诉求；同一人可能多次参加，不直接相加活动报告为独立人数。各运动有稳定ID及真实聚合/协调关系；新行动可加入既有运动或另成关联实例，避免重复计数、无因蔓延或按每个地区生成无数玩家待办。
工会重组与合并须由真实参与组织自主协商、依各自制度决定，明确旧组织、成员归属、后续职务/协议/档案承接。统一后不将旧组织会员与新组织会员重复计入，也不自动消除内部政治倾向；没有成立条件时可继续分立或有限协作，不规定1936年3月必然统一。

## 6. 运动的产生、演变与结束
按D2的有限政治主体规则：相关群体/组织面临实际问题和机会→形成或表达具体诉求→评估行动、协商、暂缓或不行动→组织/基层实际参加或不参加→对方及有关政治主体回应→运动延续、扩展、分化、暂缓、局部结束或终止。诉求可以在行动期间发生变化，但保留旧版本与原因。正式工会号召、基层行动、实际参加、劳资让步及结束分别记录。不能由全国经济单指标达到阈值直接生成全国总罢工；也不要求所有运动先有中央组织命令。
候选触发与演变因素限于有明确解释力的几类：具体社会诉求与未解决问题（D7经济/生活变化接口）、相关政策或事件、组织及基层实际参与条件、现有协调或协议、其他主体回应及既往结果。规模与阶段依实际活动、参与范围、组织支持与对方行为判断，不以加总“愤怒值”决定唯一结果；初版可用有限条件组合及D2局部序数评估，精确阈值、活动规模、概率及月度校准留D7/D8。经济不佳不保证罢工，经济改善也不保证运动终止。允许基层先行动、工会后来协调，允许工会反对或无法控制基层；不同群体可响应不同。行动和反应采用D1/D2时序、同检查点信息截面、因果ID与去重，不强制每月产生运动或NPC行为；常规新事务次月进入决策窗口，真实发生事实按原时点记录。真实到期的政治选择才阻断推进，不把每场罢工都做成必答。
运动结束不等于诉求全部达成。可出现部分让步、协商未果后继续、组织自行停止、部分地区仍行动或失败。单个协议成立只影响其实际覆盖的群体与条款；不能直接清空所有罢工，不将阶段结束记为所有参加者支持SFIO。停止、恢复及新一轮活动须有因果和时间依据；不得依靠反复切换状态制造无限奖励。

## 7. 玩家介入、劳资谈判与制度转化
玩家作为SFIO中央领导层，可在实际权限内进行政治声明、联系工会、争取其他政党协调、组织本党活动、支持/反对具体诉求、推动本党或议会采取合法政策行动、在真实政府授权下参与调解。拒绝、不介入或维持现状是合理选择。不能直接命令工会发动/终止罢工，不能支出工会资金，不能由党领导层代替工会、雇主或政府签劳动协议。党员与工会成员重叠也不产生控制权；若某职务兼任多种身份，按实际代表身份、权限及费用主体分开。不是所有介入都有积极结果。
劳资协议与党际协议复用D4的版本、成立与履约接口，但当事方、代表资格及法律效力不同。政府的调解、公共政策、行政措施按D5真实职权。工会与雇主可以独立磋商、接受、拒绝、部分让步及提出新条件；调解不等于代替双方同意。示例链：工人提出工时与集体谈判诉求→部分工会组织活动、其他群体自主参加→雇主和工会谈判、政府在有权时调解→协议达成（范围与义务明确）→相关政策如需立法则进入D5两院程序→颁布及实际实施→按覆盖范围反馈社会状况、组织行为及经济四状态（D7）。政治宣言、纲领、劳资协议、法律颁布与实际执行分别记录，不把其中任何一步自动替代下一步。马提尼翁及后续社会改革只作历史情境锚点，具体原文与实现规则待核。
社会压力可以改变政治主体关切、提出新政治议题、影响党内争论、谈判条件及政策议程；对经济四状态的作用由D7核定，有明确因果及滞后，不增加独立经济管理。罢工数或工会会员数不得直接等于SFIO选票、党资金或支持率；D6/D7通过社会群体、实际表达及选举校准处理反馈。工会支持某项改革不推定其支持所有SFIO政策或选举候选人。信息沿D2：实际行动与玩家收到的工会/地方报告分开；年度统计不冒充实时人数，不生成未发生的报告。UI04-03展示组织、诉求、实际活动和近期动态，详情仅在有实际内容时显示相关行动或报告；不新增调度按钮。

## 8. 行动成本及共用时序（候选走查）
主动发起一项具体政治接触/联合活动或追加实质性干预按实际规则可收费；接受对方正常回复、查阅条件、已有有效议程推进、按权限记录既有约定的例行程序不按操作步骤重复收费；实质反建议、追加争取授权或重新发起是否收费取决于实际政治投入，不能把每轮反建议全免费或全收费。D1统一账目、预留及实际消耗；不将对方主动发起的事务本身扣玩家额度。资金仅党资金，不将社会主体资源纳入可用余额。
虚构走查一：当月2次行动，1次推动所需党内授权（测试成本，D3实际授权结算时点需先满足），1次正式提出具体合作方案（测试成本）；等待、接收回复及正常审批程序不额外消耗。若对方反建议需要新增实质干预，可留到后续合法窗口或在截止前选择不接受；若需及时回应，保证至少一个合法零资源回应（不要求接受越权条件）。不保证两项行动必在同一月完成，不创造额外行动。走查二：基层罢工先发生→工会自行决定参与→SFIO可选择联系/支持实际诉求→雇主自主回应→若未达成协议运动可继续；玩家本月0次行动仍有实际事件与合法回应。玩家不能以免费例行执行名义强制他方参与。
多方表态、批准及到期义务的并行顺序遵循D2信息截面及实际依赖；月底常规事务进入次月正常窗口，硬截止依D1受限决策续跑，不重复扣费/重复生成协议或动作。D5政策实施、D6退选窗口、D7反馈需在60个月每月2次预算下联动走查。示例价格不冻结。
