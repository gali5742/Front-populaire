## 2. 党际关系不是单一好感度
| 维度 | 数据来源及边界 |
|---|---|
| 政治意见 | 具体议题、方案版本及最近可知表达；不据此推断所有内部立场 |
| 合作身份 | 真实联合机构、共同纲领或合作安排的参与资格及有效时点 |
| 正式协议 | 当事方、适用范围、具体条款、有效版本及生效/终止条件 |
| 实际履约 | 已到期义务、履行事实、异议及违约/补救；不等于协议存续 |
| 议会支持 | 某政府、信任或特定议案的承诺和实际表决；由D5核定 |
| 内阁参与 | 实际任命及职务关系；由D5核定；联盟不自动生成内阁席位 |
可以同时存在合作、政策分歧、部分履行及不同议会行为。联盟不是不可逆阶段树，不能以某个标签推定共同立场。多边联合机构如实际形成可有自身议程与资格，但无独立联盟资源或玩家控制所有成员；不把每次双边协议都包装成新组织。成员资格与所有签约/适用方独立查询；退出某合作安排不自动退出其他协议或内阁。UI04-02从上述同源事实投影，普通状态深灰；无实际议题不设通用改善关系/拉拢按钮。

### 2.1 D4-R02 跨组织协调机构及有限授权
多边协调机构采用轻量组织记录：稳定ID、实际组织形式、成员（政党、工会或其他自主社会组织）、加入/退出时点及范围、共同议程、实际授予权限、决定方式、代表资格和决定记录。机构可提出联合倡议、协调日程、接受新成员或进行其他已获授权的协调事项；不因成员加入而取得对其路线、资金、候选人、议会表决、参政或群众行动的控制权。
初版默认只处理实际授权内的协调与共同倡议；若没有证据支持其内部多数决或其他决定程序，不凭空生成具有成员强制效力的表决。若实际规则赋予机构特定事项的决定权，则依D3事项权限及该机构真实程序执行，不预先禁止多数决，也不把多数决自动等同于全部成员批准。成员授权内的协调决定与超出授权、需要另行批准的实质义务分开；对外署名、协议必要方及实际适用范围逐项校验。成员退出、其他协议及剩余义务分别处理，不推定机构自动解散。人民阵线全国协调机构的准确组成、章程与决策权限仍待原始资料核证，以上是候选抽象而非历史断言。不增设独立联盟经营界面、资源或常驻额外行动点；UI04-02/03与UI02读取真实联合议程及决定。

## 3. 磋商实例、方案与回应
从具体议题发起。可由SFIO或自主主体发起，既可公开也可在实际接触渠道内进行。记录议题ID、实例ID、发起方及所代表组织、必要参与方、可选参与方、各自权限、实际截止/收束条件、条款变体空间、版本、往来、答复状态、成本引用及真实成立结果。参加会谈不等于接受方案；表达赞成目标不等于对有效版本作出具有约束力的同意。D3领导层更替后按组织承接原则及新授权重验；可接收已发送提议的回复。
| 程序节点 | 规则 |
|---|---|
| 接触与探询 | 按实际职权了解意见；不自动取得谈判或签署权 |
| 提出方案 | 明确条款、必要当事方与当前有效版本；校验授权、时限及可行性 |
| 等待、答复 | 记录接受、拒绝、附条件回应、反建议、明确延后或未回复；等待不推定同意/拒绝 |
| 反建议与修订 | 仅限议题的合法有限条款空间；D2去重、收束与版本规则 |
| 内部批准 | 需要时由各方实际有权机关决定；玩家不能直接控制他党内部批准 |
| 成立与生效 | 必要当事方对同一有效版本按实际程序同意；满足签署、批准、条件及生效时间 |
| 未果、撤回、到期 | 保留已发生的声明、成本及有限成果；不凭空生成有效协议 |
可按实际事项合并步骤，不要求所有磋商逐项经过上表。不预设统一等待一个月，响应时点取决于实际程序、主体行为及期限；普通回复可在正常窗口展示，月底中断只限D1真实必答截止。附条件同意如条件已在共同版本内且确实满足，按其实际法律/政治效力处理；新条件构成反建议，不将条件性表态静默计入无条件最终同意。多方谈判若一方拒绝，不将缺少必要方的方案自动成立；若其他方拟另行签订范围较小的协议，须形成明确的当事方与有效版本、重新校验必要同意和授权，不把原多边协议标成已全部成立。秘密立场不从选项禁用原因或“成功率”泄露。给玩家实际声明、条件、已知分歧及后续合法路径；不编造拒绝理由。等待不自动产生付费项目或“查看工作”入口。

### 3.1 D4-R01 草案、待批窗口与撤回
分别记录文本一致、签署（若适用）、各方必要批准、协议成立及生效的实际时点与依据。候选显示状态包括磋商中、草案达成、待批准（有签署事实时可标已签待批）、成立待生效、正式生效，以及实际未果、批准未成、撤回或到期；按事项真实程序跳过不适用步骤，不强制签署先于批准。每一必要批准绑定具体版本、当事方、实际有权机关、状态及记录时间；草案达成不等于授权或最终同意。批准窗口应有明确收束检查点、依赖及合法延期条件；可以跨月，但不得无限等待、反复延期或通过重开规避实际硬截止。无史实日期时使用明确标注的模拟程序期限，不冒充历史日期；不设置通用一月/两月上限。
若到期未满足必要批准，按实际规则收束为批准未成/到期或合法延期；若必要方在成立或生效前撤回同意，先核验撤回资格、阶段、程序与后果，再确定是否使该版本不能成立/生效。成立待生效的协议不等同于可自由撤回的草案；既有有效同意不因政局变化或任职者更替自动作废，也不自动保证后续批准。更替后依D3-R01重验待执行权限，保留已合法作出的同意及往来；实质改版时按D2重新核验必要同意与授权。已生效协议的改约与退出依第4节，不走草案撤回路径。
最终协议尚未生效时不生成其未生效条款的正式履约义务；另有实际成立并生效的保密约定、程序约定或阶段性承诺时，独立记录效力、期限及义务，不因主协议批准未成自动抹消。到期结案保留真实批准、回复、成本及阶段义务，正常列表不继续显示为待处理；真实未结义务或有效关联事务仍可查询。到期检查本身不必然要求玩家回应，仅当确有D1硬截止的必要玩家决定时才暂停结算，并提供合法零资源回应。

### 3.2 D4-R03 磋商渠道与逐条记录可见性
磋商实例记录默认接触渠道（公开、有限接触或实际混合渠道）、参与者及相关访问范围；每条倡议、报告、条件、回复、批准、声明和披露事件独立记录来源、发生/可获得/实际获知时点、渠道、接收者、知情范围及关联版本，复用D2第6节。实例渠道只作为默认值，不覆盖逐条记录的实际权限。公开倡议可经公开渠道被有关主体观察并产生自主回应，但公开可获得不等于全部主体瞬时获知、了解内部条件或必然回应。有限接触只对实际获知者开放；提交CAP、地方联合会或其他集体机关扩大到真实有资格的党内/组织内接收者，不自动成为公开消息。
披露、转述、对外声明或实际泄露按真实事件及传播范围更新对应记录，不将一次公开声明扩展为整份谈判档案公开；同一实例可以同时拥有公开、内部与私下记录。实际可知的第三方回应可进入D2自主行为及党内争议，但不得以隐藏条件直接决定可知反馈。列表、计数、禁用原因、搜索及详情共享同源可见性；不可见记录不得经条目数量、排序、可用按钮或预报结果泄露。

## 4. 协议与联盟义务
协议为政治事实对象，不是增益卡或永久解锁。最小记录：协议ID、相关议题、类型、版本、实际当事方/代表权限、签订日期、批准/生效条件与时间、适用范围、条款、责任主体及受益/相对方、期限、例外、改约/加入/退出程序、替代关系、实际履约及争议记录。可根据真实来源区分政治声明、统一行动协定、共同纲领、选举协调、议会支持安排、联合执政安排与劳资协议；不是固定等级或每个协议必有全部条款。声明或纲领中无明确执行义务的主张不得被编造为可强制履约的硬约束。
| 可配置条款 | 示例作用（虚构） |
|---|---|
| 合作目的与范围 | 反法西斯共同活动，而非全政策联盟 |
| 共同活动与执行责任 | 各方独立组织并按约协调；不转移组织控制权 |
| 共同政策主张 | 列明共同支持的政策目标、范围与保留事项；立法和行政由D5 |
| 选举协作 | 适用选举、选区范围、退选原则及例外；D6负责候选资格、具体票转移 |
| 议会与参政 | 区分支持特定政府/法案与参阁承诺；不代替实际表决或任命 |
| 有效期限及调整 | 实际生效、期限、加入/退出、修订所需同意与程序 |
协议签订、当前效力及履约三者独立。单一状态不能掩盖条款差异：协议按第3.1节区分草案/待批、成立待生效、有效、按实际程序暂停、终止/到期等实际阶段；条款可适用/未触发/待履行/已履行/部分履行/逾期未履行/有争议/依法免除等。是否允许暂停、免除、自动终止须由具体条款规定，不添加通用“违约即失效”。历史签署日期始终保留，不把修订或加入日期重写成初次签约。
义务记录从实际生效条款生成（阶段性承诺依第3.1节独立判定），按责任方、适用时点、触发条件、所要求行为/禁止行为、完成证据和例外判定；同一义务实例只生成/结算一次。未到期不算违约；客观无法履行、政治拒绝、双方对条款解释不同及实际未履行区分，不默认任何短缺都是恶意违约。违约可产生具体质疑、谈判条件、合作暂停提议、公开批评等政治后果，须有因果桥梁与各方自主决定，不以全局关系扣分或自动解散联盟代替。义务需要执行的行动仍按D1/D3实际权限、成本与条件校验；对其他主体的政治承诺不赋予直接指挥其行为的能力。
修订与退出沿D2/D3：变更只在实际程序满足时影响未来有效条款，保留已发生履约与成本；新版本同意不可拼接，加入方明确承诺范围，原当事方义务不能被无权主体修改。退出生效前仍按有效义务处理；已有约束力的欠付或终止后仍存义务按具体规则保留。党内撤销授权不自动终止外部协议；禁止越权执行但生成真实需处理的履约冲突，可能重新授权、协调改约、依法退出或记录未履行后果。结构化条款冲突与澄清沿D3-R03，检测器不自动制造政治议程。D5/D6不得将联盟成员自动投同一票、自动退选或保证选票转移。

### 4.1 D4-R06 承诺兑现层级与D5/D6/D7反馈接口
每项具有实际义务的条款明确责任方、适用范围、承诺类型、约定行为或结果、触发/期限、完成条件、必要证据及部分履行口径；目标性主张与约定义务仍分开。承诺类型可关联具体行为（例如提出或投票支持某案）、真实程序节点（例如提交、通过、颁布）、实际实施结果（例如约定范围内劳动条件落实），而非所有承诺统一要求完成整条政策链。不得从政策主张自动生成严格结果义务；承担行为义务的一方也不因其他机关否决而自动违背其已实际完成的约定行为。
D5回传实际议案/表决/颁布/政令/实施记录及责任主体、时间、版本、范围和结果；D6回传具体选举协调的实际执行记录；D7回传已发生的相关社会经济变化。D4按有效条款对应的完成条件和真实证据逐项核验履约，不让上游程序自动填充下游结果，也不因同一事件被多个页面或协议引用而重复施加同一实际效果。若约定支持立法且实际合法表决符合条款，可判相应行为义务已履行；若约定实际落实改革，提交法案、通过或颁布只记录相关进展，不能代替实施证据。实施覆盖不全时按真实范围判断部分履行；实际履行结果与各方解释争议分开。政策被修订、撤销或发生后续变化时保留已完成的历史行为，依义务持续性及新事实重验未来义务，不回滚既往履约记录。UI04协议详情与UI05/07同源，不增加独立纲领进度分数或虚构百分比。

## 5. 自主群众运动的最小模型
群众运动是具体政治/社会事务的行为过程，不是可以储存和消耗的动员力。参与主体包括实际存在的工会（如CGT/CGTU）、行业或地方工会/基层组织、工人群体、雇主及其组织、相关政治团体；国家与行政机关依D5。普通成员不是全量个人代理；重要行业或地方活动按实际意义聚合，避免地图、产业经营与逐厂操作。保持工会组织正式决定、基层实际参加及非会员参加分离，SFIO支持不等于工会接受，不等于工人一定参加。
| 记录 | 最小必要内容 |
|---|---|
| 社会主体 | 组织身份、有效时期、相关代表、组织基础及自主诉求；具体能力而非通用资源 |
| 社会诉求 | 工资、就业、工时、集体协议、劳动权利或具体政治事件等有来源的问题与方案 |
| 运动实例 | 关联议题、发起者及实际参与群体、活动类型、适用地域/行业范围、开始及阶段时点、公开要求、组织间协调关系、实际行动/状态及结果 |
| 劳资协商 | 独立实例、实际谈判方、争议条款、回应与义务；可关联运动但不等于运动本身 |
| 报告 | 发生/获知时间、渠道、覆盖范围与不确定性；按D2可见性 |
工会会员数量是组织事实/校准依据，不是可直接消费的动员点，也不等同于所有罢工参与者。初版活动规模采用具有实际覆盖含义的有限描述（例如局部、多个行业/地区、广泛或全国性蔓延），另行记录是否存在实际组织协调及协调范围；二者不是同一升级等级，在有依据时展示实际统计及口径。不虚构精确每月参加人数、强度条或预报成功率。运动可同时具有不同地区、行业、参与者和诉求；同一人可能多次参加，不直接相加活动报告为独立人数。各运动有稳定ID及真实聚合/协调关系；新行动可加入既有运动或另成关联实例，避免重复计数、无因蔓延或按每个地区生成无数玩家待办。
工会重组与合并须由真实参与组织自主协商、依各自制度决定，明确旧组织、成员归属、后续职务/协议/档案承接。统一后不将旧组织会员与新组织会员重复计入，也不自动消除内部政治倾向；没有成立条件时可继续分立或有限协作，不规定1936年3月必然统一。

### 5.1 D4-R04 雇主组织的自主行为
全国性或主要行业/地方雇主组织与工会共享D2主体、议题、表达、正式决定、实际行为及D4协议接口；根据实际重要性聚合，不逐企业模拟，不赋予玩家雇主资源或企业控制权。共享数据模型不等于采用完全对称的行动集合、能力或制度权限。雇主及其成员企业、正式协会决定与成员的实际执行分别记录，不预设组织可命令全部企业。雇主组织可以在存在具体利益、政策、组织能力及真实权限时主动提出谈判条件、开展行业协调、向政府或议会表达诉求、提出执行申诉/调整、重组合作，以及在符合实际条件时发生拒绝落实、停工闭厂等劳资冲突行为；不必等待罢工先发生。行为是否合法、是否构成违约、是否受国家制度约束按实际规则独立判断，不把可能发生的违规行为视为合法权限。
对D5传递具体诉求、法令/行业执行争议、真实实施结果及相关权限，对D7传递实际生产、就业、投资等有因果依据的影响及时间/覆盖范围。反对声明、具体行为、国家法律效力和经济结果独立：雇主反对不自动使法令失效，不直接固定扣减景气；若未采取实际影响行为，不能预先写入经济损失。政治压力也不能自动保证参议院表决结果。CGPF等组织的真实名称、重组、权限、行业覆盖及反制史料待核，不以候选行为列表宣称具体历史行为必然发生。

### 5.2 D4-R05 运动波次与独立活动的关联
设置轻量上层运动波次记录（稳定ID、实际时段、共同诉求家族、可证关联、所属活动ID、范围、协调关系及历史变化），底层活动与各自劳资协商保持独立ID和真实记录。仅在时间关联、核心诉求及实际示范/传播/共同触发或协调联系能够支持归并时纳入同一波次；同月发生、名称相似或都属于劳动冲突不足以证明共同运动。不能确认实际联系时保留独立活动或明确的待核关联，不伪造全国统一组织。一个活动在当前主要波次统计中不得重复计入；有多个相关波次可保留交叉引用，但汇总须去重，必要时通过实际关联变化记录拆分/合并，保留原ID及历史成员关系。
覆盖范围与协调程度分开：全国性蔓延可能没有统一指挥，局部活动也可能具有正式组织协调。上层当前活动范围由仍持续的相关活动及实际可知范围汇总，不凭波次标签扩张下层实际参与群体；协调程度来自实际组织决定、联络或共同安排，不由规模自动推导。波次不是新的统一谈判方或政治主体，不取得代表各工会/行业缔约权，不新增动员点或额外操作系统。
局部协议或活动结案时，只更新真实覆盖的诉求、群体、义务及活动状态；已结案活动继续保留在波次历史中，不计作当前持续活动；未覆盖部分可继续。签约不自动等于活动停止，终止、恢复、局部让步和最终结果仍由实际主体行为及事实判定。UI04-03以可知的上层波次作为默认聚合摘要；仅有实质独立政治选择、报告或期限时提供具体活动/协商入口，复用现有详情与行动流程，不额外设计必经页面。汇总、计数和历史记录遵守D2逐条可见性，不泄露尚未获知活动或私下谈判；不把统计参加人次直接相加为独立人数。

## 6. 运动的产生、演变与结束
按D2的有限政治主体规则：相关群体/组织面临实际问题和机会→形成或表达具体诉求→评估行动、协商、暂缓或不行动→组织/基层实际参加或不参加→对方及有关政治主体回应→运动延续、扩展、分化、暂缓、局部结束或终止。诉求可以在行动期间发生变化，但保留旧版本与原因。正式工会号召、基层行动、实际参加、劳资让步及结束分别记录。不能由全国经济单指标达到阈值直接生成全国总罢工；也不要求所有运动先有中央组织命令。
候选触发与演变因素限于有明确解释力的几类：具体社会诉求与未解决问题（D7经济/生活变化接口）、相关政策或事件、组织及基层实际参与条件、现有协调或协议、其他主体回应及既往结果。规模与阶段依实际活动、参与范围、组织支持与对方行为判断，不以加总“愤怒值”决定唯一结果；初版可用有限条件组合及D2局部序数评估，精确阈值、活动规模、概率及月度校准留D7/D8。经济不佳不保证罢工，经济改善也不保证运动终止。允许基层先行动、工会后来协调，允许工会反对或无法控制基层；不同群体可响应不同。行动和反应采用D1/D2时序、同检查点信息截面、因果ID与去重，不强制每月产生运动或NPC行为；常规新事务次月进入决策窗口，真实发生事实按原时点记录。真实到期的政治选择才阻断推进，不把每场罢工都做成必答。运动波次按第5.2节动态汇总并保留底层事实；归并本身不触发新行动、奖励、成本或自动扩大实际活动。
运动结束不等于诉求全部达成。可出现部分让步、协商未果后继续、组织自行停止、部分地区仍行动或失败。单个协议成立只影响其实际覆盖的群体与条款；不能直接清空所有罢工，不将阶段结束记为所有参加者支持SFIO。停止、恢复及新一轮活动须有因果和时间依据；不得依靠反复切换状态制造无限奖励。

## 7. 玩家介入、劳资谈判与制度转化
玩家作为SFIO中央领导层，可在实际权限内进行政治声明、联系工会、争取其他政党协调、组织本党活动、支持/反对具体诉求、推动本党或议会采取合法政策行动、在真实政府授权下参与调解。拒绝、不介入或维持现状是合理选择。不能直接命令工会发动/终止罢工，不能支出工会资金，不能由党领导层代替工会、雇主或政府签劳动协议。党员与工会成员重叠也不产生控制权；若某职务兼任多种身份，按实际代表身份、权限及费用主体分开。不是所有介入都有积极结果。
劳资协议与党际协议复用D4的版本、成立与履约接口，但当事方、代表资格及法律效力不同。政府的调解、公共政策、行政措施按D5真实职权。工会与雇主可以独立磋商、接受、拒绝、部分让步及提出新条件；调解不等于代替双方同意。示例链：工人提出工时与集体谈判诉求→部分工会组织活动、其他群体自主参加→雇主和工会谈判、政府在有权时调解→协议达成（范围与义务明确）→相关政策如需立法则进入D5两院程序→颁布及实际实施→按覆盖范围反馈社会状况、组织行为及经济四状态（D7）。政治宣言、纲领、劳资协议、法律颁布与实际执行分别记录，不把其中任何一步自动替代下一步。马提尼翁及后续社会改革只作历史情境锚点，具体原文与实现规则待核。
社会压力可以改变政治主体关切、提出新政治议题、影响党内争论、谈判条件及政策议程；雇主可按第5.1节主动产生同类政治事务，承诺兑现依第4.1节逐条款核验；对经济四状态的作用由D7核定，有明确因果及滞后，不增加独立经济管理。罢工数或工会会员数不得直接等于SFIO选票、党资金或支持率；D6/D7通过社会群体、实际表达及选举校准处理反馈。工会支持某项改革不推定其支持所有SFIO政策或选举候选人。信息沿D2：实际行动与玩家收到的工会/地方报告分开；年度统计不冒充实时人数，不生成未发生的报告。UI04-03展示组织、诉求、实际活动和近期动态，详情仅在有实际内容时显示相关行动或报告；不新增调度按钮。

## 8. 行动成本及共用时序（候选走查）
主动发起一项具体政治接触/联合活动或追加实质性干预按实际规则可收费；接受对方正常回复、查阅条件、已有有效议程推进、按权限记录既有约定的例行程序不按操作步骤重复收费；实质反建议、追加争取授权或重新发起是否收费取决于实际政治投入，不能把每轮反建议全免费或全收费。D1统一账目、预留及实际消耗；不将对方主动发起的事务本身扣玩家额度。资金仅党资金，不将社会主体资源纳入可用余额。
虚构走查一：当月2次行动，1次推动所需党内授权（测试成本，D3实际授权结算时点需先满足），1次正式提出具体合作方案（测试成本）；等待、接收回复及正常审批程序不额外消耗。若对方反建议需要新增实质干预，可留到后续合法窗口或在截止前选择不接受；若需及时回应，保证至少一个合法零资源回应（不要求接受越权条件）。不保证两项行动必在同一月完成，不创造额外行动。走查二：基层罢工先发生→工会自行决定参与→SFIO可选择联系/支持实际诉求→雇主自主回应→若未达成协议运动可继续；玩家本月0次行动仍有实际事件与合法回应。玩家不能以免费例行执行名义强制他方参与。
多方表态、批准及到期义务的并行顺序遵循D2信息截面及实际依赖；月底常规事务进入次月正常窗口，硬截止依D1受限决策续跑，不重复扣费/重复生成协议或动作。D5政策实施、D6退选窗口、D7反馈需在60个月每月2次预算下联动走查。示例价格不冻结。
