# 历史底库与模拟数据的使用规范
历史依据以 [v0.6原始交接](../research/phase0-v06/PHASE0_HANDOFF.md) 和 [审计记录](../research/phase0-v06/audit.json) 为准。本文件不修改原始历史数据。

## 数据状态
v0.6 CLOSED_WITH_GAPS；50个文件（47张CSV、2份Markdown、1份JSON），180项来源、30个专题、2,823条CSV记录（含来源、索引、注释和非数值记录，并非全部独立数值观察）；36条差异登记、827条经济观察。格式及来源引用等技术审计通过；全面史实准确性审计未完成。
原始ZIP保留，解包表是供查阅与后续导入的证据层。不会以游戏简化为由删除H01–H30中的史料。

## 使用纪律
- 原表、转录、目录、学术解释、派生参数分层；保留来源、日期、单位、覆盖范围、频率、估计性质。
- 不同口径的史料不平均；空值不是零；年度统计不能充当开局当日状态；1934缺值不得用1935/36资料倒填。
- 选举票数与党团人数、法定席位与统计覆盖席位不同；1933年党内分裂后不能直接沿用1932年席位。
- 内阁组阁名单不是逐人完整任期；次官、改组及任免日期需另核；历史政府职位不因界面简化合并。
- 真实历史事前信息与本局已发生的政治事实分开。玩家不可因档案提前获得游戏尚未发生的事件信息。
- 所有用于游戏的派生值应记录来源或假设、适用时期、转换方式与不确定性；本次不执行数值参数化。
- 原始来源许可和数字化授权尚未全面审查。图像原型中的历史场景为示意，不是档案照片；正式使用需核实出处与授权。

优先补足开局党团和CAP、1932/1936逐选区原始两轮票及候选人、内阁及其改组、SFIO实际经费及党费、地区组织、工运与关键经济状态。缺口详见原交接与 topic_register.csv、phase0_gate.csv、discrepancies.csv。
Cagé/Piketty 市镇数据、TRF-GIS、CEPII 和 ICPSR 8421 等外部原档此前存在获取阻断，不声称已取得。
正式事件应分别标注历史来源与玩家可改变的内容；不能把示例政治结果当成历史事实。

## 视觉示例与历史事实
《人民报》为 Le Populaire，勿用共产党方面的 L'Humanité 替代。1934年开局众议院SFIO席位需核验，界面使用“待核定”；约13万党员、47万法郎、各项项目金额和周期仅用于示意，不直接作为正式开局。1936年国民议会换届与地方选举不同，不虚构1934年春季固定全国换届任务。二月事件场景的背景月份应保持一致。历史人物与事件图片须与文字时间、主题一致。
