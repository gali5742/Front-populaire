## 政治子系统及其边界
| 子系统 | 功能方向 | 未定或限制 |
|---|---|---|
| 党内 | CAP、党内路线、派系、地方联合会、代表大会、决议和授权 | 代表票权、初始构成、表决算法待核定 |
| 政党关系 | 接触、磋商、正式协议、联盟义务及对方回应 | 接受条件与回应时机待定；获得授权不保证对方接受 |

| 议会 | 议会提案、质询、表决、政府信任及参议院阻力 | 逐案程序、票数及政治联盟规则待细化 |

| 执政 | 联合政府、内阁职务、政策实施、其他政治力量制约 | 权限矩阵、内阁改组与政策执行机制待定 |

| 地区 | 后台选区与组织分布体现历史差异 | 不新建独立地图经营玩法 |

## 行动与事件
常驻行动按党务、宣传、议会、政党关系、群众运动等分类；限时政治机会随局势出现。行动内容而非所属机构构成卡牌标题。可用条件、固定或变量成本由同一实际规则读取。不可执行不等于不可查阅。
行动可即时执行、安排至月底、启动长期项目或等待其他主体回复。已安排但未执行时预留资源，可撤销；已执行后不得撤销已产生的政治后果。是否重复执行取决于行动规则，不设统一冷却。
必须回应的事件可暂时关闭以查阅信息，但未决时禁止结束本月；即使行动耗尽也必须存在合理且不消耗行动的回应，避免死锁。可选事件可放弃或失效。

## 回合闭环（行为约束，内部结算顺序待定）
1. 新月：形成简报、局势变化、可用行动、待回应事务及项目进展。
2. 玩家阅读、进行行动、获得即时反馈或建立待处理/等待回应记录；可查阅党务、政治及档案。
3. 回合结束校验未决重大事务；有未用行动不构成阻止条件。
4. 推进时间，处理已安排工作、持续费用、各主体行动及延迟事件；更新记录和次月状态。
不得将以上界面流程直接视作已确定的经济结算与事件调度算法。

## 长期工作
区别有限期项目、持续活动、政治谈判；只有前者使用明确的时间进度。预计总支出随投入方案变动，工作成果不承诺固定百分比。启动前撤销释放预留资源；启动后终止不退还已投入费用。投入变更不重置既有进展。经费不足需要通知玩家并提供处理路径，不静默形成负资金。
支付时点、变更投入是否消耗行动、是否可暂停及终止生效时间的完整规则待机制阶段核定。视觉示例中的月份与费用不构成正式参数。

## 记录和可解释性
区分发生的事实、玩家决议、对方回复、等待状态及预计后果。资源消耗准确显示；政治反馈具体叙述；历史记录只读。历史事实、架空模拟事实及假设参数保持独立。
