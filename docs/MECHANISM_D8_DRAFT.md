## 2. 数据分层、初始化门及三类运行配置
原始证据层保留数据原样；派生/参数层为可追溯转换、估计或合成假设；本局事实层为实际状态、事件、交易及可知报告。每个初始化字段/参数记录稳定ID、单位/覆盖、适用时点/版本、来源ID或明确假设ID、转换方法、证据质量/缺失状态、用途（初始化、当时可知、仅离线校准）、依赖及复核状态；参数变化保留版本。历史来源缺失（开发者未核）、本局信息未知（D2）、明确零、无适用事项必须分离。未知数值不得隐式转0、均值或默认票权；必要规则缺失时只能选已显式声明的测试假设或阻断相应历史配置加载，不能边玩边用虚构史实补洞。合成数值允许具体计算但前台明确测试配置身份，不能将虚构政治事实作为真实历史注释；不将开发者缺证装作游戏内情报谜题。

## 5. 共用执行契约及检查点次序
D1/D2已有稳定ID、事项权限、实际/可知/历史分层。实现候选以单一状态源与明确命令/事实记录为核心，不要求完整事件溯源架构、特定数据库或分布式服务。至少维护：主体/身份时效、议题与版本、决议授权、协议/条款、议案/两院票权、选举轮次与资格、政府及职务、政策/影响、账目/义务/项目、检查点、事实及披露记录。业务对象保持独立ID，关联关系与版本可追溯，页面只读投影；状态迁移和已结算标记与账目原子提交。命令有稳定请求ID、主体/角色、目标、版本、可知确认内容、时点、资源及前置条件，提交/实际执行重验权限和最新条件；失效释放尚可撤销预留，实际政治结果不回滚。重复请求返回已有结果或明确拒绝，不再次支付/表决。存档至少含配置/规则版本、种子及随机状态、当前时点/阶段、真实状态、待处理队列及依赖、已处理ID、账目/预留、可见记录；恢复不得重抽、重发点或跳过截止。版本不兼容时明确阻断/迁移，不静默修订历史。
候选调度顺序（按实际时点和依赖，而非固定一张月末流程图覆盖全部情况）：
| 检查点 | 执行契约 |
|---|---|
| 合法进入新月 | 封存前月、切换月份；发2次且只发一次；按当时真正到期的收入/义务、已有效预留及实际依赖处理支付/下一期预留；无日期批处理不得越过真实早期窗口 |
| 早期前置窗口（如1936年5月） | D83仅开放当时实际合法事务及同期真实期限；按目标推进第二轮等检查点，保留本月余量进入普通阶段 |
| 普通决策 | 查阅与实际提交分离；即时行为按时点执行，未来预约预留；真实早于下一窗口的依赖显式处理，不给未来结果提前权限 |
| 月内有日期程序/事件 | 依时间、因果、真实截止执行，必要玩家决定在点前暂停；D83选举窄例外、D84党账处置依既有条件，不广泛重开普通行动 |
| 无日期普通月末批处理 | 在不跨越更早硬检查点前提下推进未开始预约/项目及自主事务；经济常规更新、实际付款和后续报告按因果时点，不倒序使用尚未发生数据 |
| 封存与末月结束 | 校验仍在当月真实到期的必答/程序，记录实际结果、跨月合法事务及结算ID；12月末按第7节结束，不产生第61个月 |
同点因果依赖先行；无依赖的自主意向从一致快照形成，再按实际权限及冲突规则处理（D2）。不可相容的真实期限与权限记录不可行结果，不把时间推迟以强制成功；无合法排序的依赖环视为配置/实现缺陷，不靠随机或遍历顺序。剩余额度不足仍应有合法零资源路径。月末经济变化引发普通新政治事务默认下一合法窗口，真实更早硬事件另依D1；不可通过经济→工运→经济即时递归无限生成。完整事件/记录字典和同点具体执行优先表在F1实现前登记，现有D1规则优先于实现便利。
 
## 6. 历史情境覆盖与反事实走查

## 7. 结局、难度及平衡候选（M-07）
初版终局以1938年12月所有适用检查点封存后为主，保留实际党组织、党内路线、议会和政府地位、有效协议/义务、社会运动、已实施政策及四项经济状态的只读总结，注明尚未完成的在途事务；不模拟1939、不发第61月行动、不提前揭示固定历史未来。不设置统一胜利分、历史目标打勾表或“复现人民阵线即胜利”；玩家的政治成败可以从多个事实维度自行判断。议会选举失败、未入阁、政府倒台、党内路线落败、资金不足、合法领导更替本身不自动终局。若合法中央组织在本局确实消失且没有可承接的组织决策主体，才考虑提前终局（禁止/解散/合并与组织实际存续及继承分开；具体制度和可玩边界待用户及史料确认）；F1可用显式测试终止条件，未确认的情形不擅自实现强制结束或默认玩家控制其他党。终局与技术死锁、损坏存档分开；技术故障不可冒充结局。
难度：首轮实现及平衡先使用一个公开说明的基准测试配置，不预设多个难度、不自动为玩家增加行动、资金或修改合法票权。若后续需要难度设置，应在体验测试后由用户确认，采用明确的初始资源/信息/行为参数等范围而非隐藏强制历史、非法权限或硬改法定制度；不预先冻结难度档位。平衡检查包括不同决策路线、有限协商、反复刷同一行动、零行动选择、合法失败、主动成本与收益、信息透明性和数月反馈间隔。不能仅以胜率高低或历史重演作为平衡通过；记录实际多路线结果和可解释原因。
