## 2. 数据分层、初始化门及三类运行配置
原始证据层保留数据原样；派生/参数层为可追溯转换、估计或合成假设；本局事实层为实际状态、事件、交易及可知报告。每个初始化字段/参数记录稳定ID、单位/覆盖、适用时点/版本、来源ID或明确假设ID、转换方法、证据质量/缺失状态、用途（初始化、当时可知、仅离线校准）、依赖及复核状态；参数变化保留版本。历史来源缺失（开发者未核）、本局信息未知（D2）、明确零、无适用事项必须分离。未知数值不得隐式转0、均值或默认票权；必要规则缺失时只能选已显式声明的测试假设或阻断相应历史配置加载，不能边玩边用虚构史实补洞。合成数值允许具体计算但前台明确测试配置身份，不能将虚构政治事实作为真实历史注释；不将开发者缺证装作游戏内情报谜题。

### 3.1 D8-R03 正式信息骨架与交互组件前置
G2起直接按已确认UI01–08信息架构构建可持续复用的真实前端，而非临时玩家表单后整体重写。共享组件包括全局顶底栏、一二级导航、局势与工作抽屉、无填色只读表格、统一行动查看/确认/费用/反馈/撤销、弹窗栈及真实返回/关闭、父级筛选及浏览位置保留、摘要与档案入口。G2先接入UI01/02/08及共享组件，G3–G5按实际模块补全。未实现入口明确不可用或不提供具体操作，不伪造可点击功能、数量和政治结果。独立开发诊断工具不得混入正式玩家查询；正式UI仅访问§5.1 PlayerView。

### 4.1 D8-R01 唯一权威来源与写入路径
Q01–Q05、Q17–Q18为7项模型演化量候选，按适用规则及实际因果影响推进；Q17若经G1确定可由其他权威事实与规则完全计算，则采用只读派生，不为维持分类数量另造可写真值。Q07/Q08为2项账目存量，以经核定期初快照及真实交易/合法调整为权威推进路径；初始化、原子交易及明确版本迁移/恢复之外，不允许政策、事件、UI或其他模块直接手改余额/债务。交易、受影响账目、义务履行及去重记录同一事务提交，失败不留下部分结果；从期初及流水可重算核对存量。Q06及Q09–Q16为9项只读派生/聚合量，依据同口径经济状态、实际流水与义务记录计算，禁止独立赋值或手动加减。Q15/Q16按实际时点、窗口、义务状态聚合；重叠范围不得再计额外债务。
允许缓存、快照和物化投影，但绑定权威版本、时点及口径，可失效重建，不得反向写入或将不一致缓存视作真值。G1明确唯一写入入口及类型/契约；G2起测试账目路径，G5覆盖所有Q01–Q18、重算、恢复与故障注入。18项仍为预算，不要求物理字段与表格一一对应，不因派生实现增加未经审阅的独立核心经济量。

参数登记必须覆盖：初始状态及选区/群体规模与分布、票权/程序/授权规则、主体判断规则与有限协商收束、行动价目与经费、组织/项目支付规则、影响幅度/方向/滞后/替代、融资/财政及状态分类、信息时效、情境触发、结束及测试种子。每项列明ID、适用版本、默认测试值或明确待填、合理域/单位、来源或假设、敏感性范围、验收用例和复审状态。F1允许显式小型确定性测试价格（如1行动、指定F金额），F2须有每种实际可提交动作的价目及条件，不允许“待定”在运行时默认为0；F3在运行前对关键近似审阅。当前只冻结候选清单及约束，不虚构最终经济系数或1934初值。校准先验证会计/票权守恒、单因果及边界，再做多月敏感性与历史近似走查；绝不以硬编码1936/1938历史结果作为达标。对于真实外部冲击注明独立性、日期精度及本局适用条件；未取原档保持证据缺口。
 
## 5. 共用执行契约及检查点次序
D1/D2已有稳定ID、事项权限、实际/可知/历史分层。实现候选以单一状态源与明确命令/事实记录为核心，不要求完整事件溯源架构、特定数据库或分布式服务。至少维护：主体/身份时效、议题与版本、决议授权、协议/条款、议案/两院票权、选举轮次与资格、政府及职务、政策/影响、账目/义务/项目、检查点、事实及披露记录。业务对象保持独立ID，关联关系与版本可追溯，页面只读投影；状态迁移和已结算标记与账目原子提交。命令有稳定请求ID、主体/角色、目标、版本、可知确认内容、时点、资源及前置条件，提交/实际执行重验权限和最新条件；失效释放尚可撤销预留，实际政治结果不回滚。重复请求返回已有结果或明确拒绝，不再次支付/表决。存档至少含配置/规则版本、种子及随机状态、当前时点/阶段、真实状态、待处理队列及依赖、已处理ID、账目/预留、可见记录；恢复不得重抽、重发点或跳过截止。版本不兼容时明确阻断/迁移，不静默修订历史。
候选调度顺序（按实际时点和依赖，而非固定一张月末流程图覆盖全部情况）：
| 检查点 | 执行契约 |
|---|---|
| 合法进入新月 | 封存前月、切换月份；发2次且只发一次；按当时真正到期的收入/义务、已有效预留及实际依赖处理支付/下一期预留；无日期批处理不得越过真实早期窗口 |
| 早期前置窗口（如1936年5月） | D83仅开放当时实际合法事务及同期真实期限；按目标推进第二轮等检查点，保留本月余量进入普通阶段 |
| 普通决策 | 查阅与实际提交分离；即时行为按时点执行，未来预约预留；真实早于下一窗口的依赖显式处理，不给未来结果提前权限 |
| 月内有日期程序/事件 | 依时间、因果、真实截止执行，必要玩家决定在点前暂停；D83选举窄例外、D84党账处置依既有条件，不广泛重开普通行动 |
| 无日期普通月末批处理 | 在不跨越更早硬检查点前提下推进未开始预约/项目及自主事务；经济常规更新、实际付款和后续报告按因果时点，不倒序使用尚未发生数据 |
| 封存与末月结束 | 校验仍在当月真实到期的必答/程序，记录实际结果、跨月合法事务及结算ID；12月末按第7节结束，不产生第61个月 |
同点因果依赖先行；无依赖的自主意向从一致快照形成，再按实际权限及冲突规则处理（D2）。不可相容的真实期限与权限记录不可行结果，不把时间推迟以强制成功；无合法排序的依赖环视为配置/实现缺陷，不靠随机或遍历顺序。剩余额度不足仍应有合法零资源路径。月末经济变化引发普通新政治事务默认下一合法窗口，真实更早硬事件另依D1；不可通过经济→工运→经济即时递归无限生成。完整事件/记录字典和同点具体执行优先表在F1实现前登记，现有D1规则优先于实现便利。
 
### 5.1 D8-R02 玩家可见投影（PlayerView）及信息边界
引擎完整世界状态（概念名WorldState）与玩家UI之间设统一只读查询/投影契约（概念名PlayerView，非提前冻结语言或框架）。UI只接收依D2当前时点、角色、来源、获知范围及授权过滤后的视图及可公开命令结果；正常玩家组件、UI状态仓库、路由不得直接持有或查询全知状态再自行隐藏字段。投影可分页，不要求构建整套大对象。摘要、详情、搜索、筛选、排序、分页总量、计数、空态、关联跳转、通知、可用操作与禁用理由均在同一边界生成；不得通过隐藏对象数量、排序或错误细节泄露。实际命令由引擎独立重验真实权限、资源、条件与时点，不以视图授予权限；拒绝时仅返回可知通用理由或已获知信息，不因隐藏信息虚构成功或失败。实际可知后果按D2披露。
G1定义查询/命令契约与依赖边界，G2即验证UI不依赖全知状态。配对非干扰测试：保持两个测试世界的可知记录、公开条件、角色、时点和命令序列一致，仅改变尚未披露的政治意向/未来事实；在实际可知结果发生差异前，正常查询、排序、计数、禁用理由、公开错误、提交前预览不得出现可推断隐藏事实的差异；合法命令产生真实可知后果后允许按披露分岔。完整存档、诊断、导出独立于正常查询，禁止将原始完整存档直接作为玩家档案展示。离线单机此边界只防正常交互泄露，不是抵抗开发者工具、修改存档或逆向的安全/防作弊边界，不因此引入服务器、加密存档或反作弊系统。

## 7. 结局、难度及平衡候选（M-07）
初版终局以1938年12月所有适用检查点封存后为主，保留实际党组织、党内路线、议会和政府地位、有效协议/义务、社会运动、已实施政策及四项经济状态的只读总结，注明尚未完成的在途事务；不模拟1939、不发第61月行动、不提前揭示固定历史未来。不设置统一胜利分、历史目标打勾表或“复现人民阵线即胜利”；玩家的政治成败可以从多个事实维度自行判断。议会选举失败、未入阁、政府倒台、党内路线落败、资金不足、合法领导更替本身不自动终局。F2最小提前终局规则见§7.1；F3实际组织存续、承接及历史规则仍需补证，不默认玩家控制其他党。终局与技术死锁、损坏存档分开；技术故障不可冒充结局。
难度：首轮实现及平衡先使用一个公开说明的基准测试配置，不预设多个难度、不自动为玩家增加行动、资金或修改合法票权。若后续需要难度设置，应在体验测试后由用户确认，采用明确的初始资源/信息/行为参数等范围而非隐藏强制历史、非法权限或硬改法定制度；不预先冻结难度档位。平衡检查包括不同决策路线、有限协商、反复刷同一行动、零行动选择、合法失败、主动成本与收益、信息透明性和数月反馈间隔。不能仅以胜率高低或历史重演作为平衡通过；记录实际多路线结果和可解释原因。
 
### 7.1 D8-R05 合法决策主体消失与提前终局
F2最小确定性提前终局条件：有本局实际有效组织事实及明确规则依据，SFIO的可玩合法中央组织已消失或丧失当前可玩范围内的合法中央决策资格，且无依D3及适用规则能够合法承接的中央决策主体。取缔、解散、合并是可能原因，不凭标签或法令提出/通过自动终局；核验实际生效、组织存续、承接资格及生效时点。仍有合法承接、过渡或待完成真实继任程序则继续；暂时空缺、没有可用行动、败选、倒阁、在野、路线落败、资金为零或数据加载缺失均非终局条件。缺必要状态/规则为配置或实现阻断，不伪造组织消失；F1可用明确测试规则，F3历史合法性和承接条件另核。
满足条件后在实际有效检查点原子封存状态与原因/依据，保留已发生政治事实、账目、有效义务、预约及在途事项的真实状态、可知总结；不虚构结算未来月份、补发额度、返还费用、取消债务或执行未发生政策。同点必要前置事项按实际依赖处理；终局后停止玩家命令及时间推进，只读总结/档案依D2可见性，恢复保持同一终局，不重复结算，不泄露未来史实或隐含状态。不新增地下党、流亡或转控其他党玩法；仍有超出本游戏范围的组织存续而无合法可玩承接时，说明可玩范围终止，不声称政治意义上的组织已完全消失。其他挫败继续至1938年12月末；技术死锁、无合法排序、存档损坏为缺陷而非结局。
