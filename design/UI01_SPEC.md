# UI01 · 主界面与回合操作
状态：四种主界面视觉状态已暂定通过，按以下规范实现。游戏名为“人民阵线”。

## 页面构成
1. 顶部低调游戏名、副标题、导航：行动／党务／政治／档案，设置入口。状态栏显示月份、SFIO及在野/执政身份、党员规模、众议院席位、资金。资金明细按需展开；历史缺值显示待核定。剩余行动不在顶栏。
2. 本月政治简报：普通月份标题、简短叙事、有关事务入口；右侧留白不强行填补局势摘要。重大事件有叙事价值时配图，标签“特别报告”与“待回应事务”不同时叠加。
3. 政治行动：标题旁展示剩余行动，如2/2；按全部、党务、宣传、议会、政党关系、群众运动、本月政治机会等分类。分类及卡牌实际数量由局势和规则决定，不是固定只展示六张；机构入口仍可通过分类或其他页面查阅。
4. 主要区域展示具体政治行动卡；示例为讨论统一战线路线、扩大基层组织、发表政治社论、提出议会质询、接触共产党、工会的联合行动邀请。常规行动纯文字，限时机会可用小幅图、暗红标签与期限强调。强调时效不表示系统推荐。卡底显示成本：固定值、起价或视方案而定；长期支出必须注明每月。条件不足显示原因，仍可查阅。
5. 本月工作记录：短摘要、实际结果、已安排/已执行区分及详细记录入口。没有行动时显示简短提示；安排可撤销，执行后不可撤销。剩余行动扣除已执行和预留之和，释放时同步更新。
6. 底栏：工作项目、历史简报，结束本月及其必要状态提示。取消固定“下一步”任务提示，避免引导历史最优路线。

## 折叠侧栏
右缘竖向“局势与工作”标签，默认折叠（宽屏也不默认展开）。覆盖式抽屉，不挤压主区域。局势摘要使用定性状态和有意义的变化原因，可点击详情；包括党内状况、联盟关系、社会气氛、国家财政等示例，不等于新增统一量化资源。
侧栏长期工作显示项目状态、剩余时间（有限期）、实际费用及工作目标；持续性活动只显示状态与维持投入，谈判用阶段及未决问题。工作有新进展或重大局势变化时显示克制的提示点，查看后清除。长期紧张不持续亮红点；真正必须回应的事项进入主界面。

## 回合状态联动
| 条件 | 提示及控制 |
|---|---|
| 无必须处理事务 | 可结束本月 |
| 尚有主动行动 | 中性提示剩余次数，可结束 |
| 限时机会月底失效 | 提示时效，可放弃 |
| 尚有必须回应的事务 | 底栏暗红警告可点击重新打开，结束本月禁用 |
| 多项必须回应 | 打开待回应列表 |
| 已处理全部 | 移除阻断，记录决定 |

事件可以暂时关闭以查阅信息，不代表已处理。即使行动已耗尽，也必须存在至少一个合理且不消耗行动的必答选项。
